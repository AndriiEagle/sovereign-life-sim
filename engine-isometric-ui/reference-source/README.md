# Перенесені оригінальні джерела Emberglass

Два точні snapshots: `iso-kit-renderer.js` (Canvas/камера/click-to-tile/depth order) та `iso-worldpack-v11.js` (12×12 world-pack/schema/reachability). Вони скопійовані за поточним дозволом власника для **цього приватного проєкту**; SHA256 і джерела — у `audit/source-copies.json`.

Вони **не виконуються** вебдемо. Для запуску потрібні перевірений власний atlas + manifest, заміна Emberglass asset IDs, узгоджений state adapter і окрема перевірка рендера/вводу. Оригінальні game/native assets сюди не скопійовані. Знайдені в попередньому каталозі адаптерні, hash/rollback дефекти не вважаються виправленими.

Публічні/комерційні права не встановлені. Немає нового дозволу на Arcanum, Outlive, сторонні зображення чи пов’язані матеріали. Незалежна CSS-карта в батьківській теці використовує лише нову процедурну графіку. Не прирівнювати її перевірку до приймання цих snapshot-ів.
