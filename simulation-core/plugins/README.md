# Runtime plugins

RuleForge creates content-addressed JSON and Python artifacts under `generated/` (ignored by Git).
The durable registry is in the private runtime journal. Python is executed only inside a checked rootless OCI worker, never imported into the server.
Both formats return allowlisted declarative operations. Rules activate once, at the next tick boundary; new tower economics then run in the shared core.
Rolling back a rule does not refund already applied expenses or erase the audit journal.
