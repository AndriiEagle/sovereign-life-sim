# ARGON · Останній трамвай

Завершена коротка локальна глава: Stadelhofen → Bellevue → Altstadt → майстерня Ади.
Вибір маршруту, ігровий час і витрати, предмети, код камери схову, розмова,
перевірка прототипу та три фінали. Усі персонажі, зустрічі, розклад, сили й CHF
вигадані; реальних оплат, моделей або акаунтів немає.

```powershell
python -B scripts/serve_argon.py
# http://127.0.0.1:4532/
python -B -m unittest discover -s tests -p test_argon.py -v
```

Обери мітку на сцені й дію праворуч. Миша пересуває героя; 1–7 обирають предмет,
E виконує першу доступну дію, J відкриває щоденник. Кнопки також доступні з Tab.
Підказка до камери схову міститься на квитанції біля табло. Можна повернутися
між локаціями; альтернативний кабель і відпочинок захищають від глухого кута.

Автозбереження після кожної дії — приватний `.runtime/argon/events.jsonl`:
використано наявний Store із блокуванням, hash chain, fsync та idempotency.
«Зберегти» створює `.runtime/argon/checkpoint.json`; «Завантажити» перевіряє
версію, хеш світу, checksum і заново відтворює дозволені дії. Пошкоджений або
несумісний save відхиляється. «Нова гра» зберігає ручну контрольну точку.
Для backup зупини сервер і скопіюй усю теку стану; інший шлях — `--state-dir`.

При втраті відповіді непідтверджений запит лишається в sessionStorage цієї вкладки.
«Повторити підтвердження» використовує той самий ID, у тому числі після reload.
Перевірка revision захищає від повторного ходу зі старого стану в іншій вкладці.
Це лише локальний запит гри, без аналітики або збирання персональних даних.

Візуал — Canvas 2D з обмеженням 30 оновлень/с і пропуском рендеру в прихованій
вкладці. WebGL/GPU-моделі не використовуються. Код запускається без інсталяцій.
Малювання Bellevue, Altstadt і майстерні оригінальне; станція теж має процедурний
fallback. За бажанням `--art-dir <Argon_Q3_Scene>` читає тільки три точно названі
вже наявні PNG-шари станції. Оригінальні джерела read-only, не копіюються і не
публікуються; немає імпорту Arcanum/Outlive чи залежності від MiroFish.

Це одна завершена глава, а не твердження про готовність усієї майбутньої Argon.
